05 · Method

Assumptions, Stated Plainly

Value proxy

value_saved = 120 × num_products + 0.02 × balance

The $120 per product is an annual relationship value order of magnitude for retail banking (fees, interchange, cross-sell). The 2% is a net interest margin on deposits. A pure balance proxy would value the roughly one third of zero-balance customers at zero, so the per-product term keeps multi-product customers visible to the engine.

Incrementality

This targets customers by churn probability, not persuadability. True incrementality would need uplift modeling and treatment data this dataset does not have.

The backtest assumes an offer saves a would-be churner with probability equal to the success rate and does nothing for a non-churner. That is a stated simplification, not a causal claim.

Architecture

Training is offline and serving is static. Five-fold out-of-fold scoring with an isotonically calibrated LightGBM writes JSON artifacts, and FastAPI only hands out files. The sliders re-rank every customer client-side, so there is no inference on request.
